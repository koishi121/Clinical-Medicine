# 模拟试卷 · 登记与处理流程

> 用途:存放/登记你手上的**模拟试卷 PDF**(自购正版),题目+答案汇总后反哺正库卡片。
> 处理管线:`tools/pdf_text.py`(文字/OCR) → `本目录\汇总\模拟试卷汇总.md` → 一题对一张卡。

## 📥 放入规则(方便处理)
- PDF 直接放本目录:`资料\模拟试卷\`(建议文件名带年份/卷号,如 `2026模拟卷一.pdf`)
- 放好后**告诉我"已放入+文件名"**,我自动:
  1. 读取/OCR 提取文本(PDF 扫描件也不怕,pdf_text.py 双通道)
  2. 解析「题干+选项+答案+解析」结构 → 生成 `汇总\模拟试卷汇总.md`(按系统/单元分组)
  3. **结构检查**:√ 每题答案完整、√ 考点归类正确、√ 与正库卡对照无缺
  4. 给你**嵌合方案**:每题挂到对应病种卡 / 标注到考点提示 / 供阅读器刷题

## 📄 汇总文件预期结构(等 PDF 到位后生成)
```
资料\模拟试卷\汇总\模拟试卷汇总.md
  一、呼吸系统         # 章节=同名正库系统
    2026-卷一-#5  咳嗽咳痰发热→题干摘要 (关联卡:肺炎)  答案:A  解析精要…
    2026-卷一-#8  … (关联卡:慢阻肺) …
  二、心血管系统
  …
```
- 每题标注:**题号、题干要点、答案、一句解析、关联正库卡(文件名链接)**
- 也可按「第一～三站」单独归技能题

## 嵌合方式(正式做时会具体给出)
1. **卡 → 题**:每张病种卡 `考点提示` 下加一行「📝 模拟题:卷X-#N」反链
2. **题 → 卡**:汇总里每题都有卡链接;刷题即复习该卡
3. **阅读器**:汇总页被 `索引.html` 收录,可按"模拟试卷/题目"搜索页内直读
4. 解析中把**高频错点**改进对应卡的「考点提示」

> 提示:请确认 PDF 为自购正版;汇总仅用于个人学习整理,不对外分发。
