# 模拟试卷 · 登记与处理流程

> 用途:存放/登记你手上的**模拟试卷 PDF**(自购正版),题目+答案汇总后反哺正库卡片。
> 处理管线:`tools/pdf_text.py`(文字/OCR) → `本目录\汇总\模拟试卷汇总.md` → 一题对一张卡。

## 📥 放入规则(方便处理)
- PDF 直接放本目录:`资料\模拟试卷\`(建议文件名带年份/卷号,如 `2026模拟卷一.pdf`)
- 放好后**告诉我"已放入+文件名"**,我自动:
  1. 读取/OCR 提取文本(PDF 扫描件也不怕,pdf_text.py 双通道)
  2. 解析「题干+选项+答案+解析」结构 → 生成 `汇总\模拟试卷汇总.md`(按系统/单元分组)
  3. **结构检查**:√ 每题答案完整、√ 考点归类正确、√ 与正库卡对照无缺
  4. 给你**嵌合方案**:每题挂到对应病种卡 / 标注到考点提示 / 供阅读器刷题
