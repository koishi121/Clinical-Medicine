## 两种使用场景

- **备考(平时)**:进 `考试\03_临床医学综合\<系统>\` 刷病种与检查速查 Markdown;基础/人文/预防查 `考试\01..04\` 的大纲考点清单。
- **规培(轮转中)**:进 `规培\内科\<科室>\README.md` 看该科室常见病种清单,点链接直达正库卡片并打卡。

## 组织方式

- **正库**:`考试\03_临床医学综合\` —— 每个病种一张卡片(**唯一正本**,按临床系统组织)。
- **规培区**:`规培\内科\` —— 科室首页只列病种清单 + 链接,不复制内容(避免双份撕裂)。
- 术语与约定见 `CONTEXT.md`;架构决策见 `docs\adr\`。
