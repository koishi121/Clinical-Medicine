使用顺序：先在科室首页选病种并看正库卡，再到实训稿按**分诊 → 问诊/查体 → 鉴别 → 检查 → 治疗与护理 → 复评和交接**练习。只用虚构病例；药物规格、剂量、途径、频次、疗程、禁忌和监测项目逐项与带教及本院 HIS/药事规范核对。出科前能解释“为什么开、什么时候看结果、什么情况升级处理”，比背一张固定医嘱单更重要。

## 使用
- 进科前:翻一遍该科首页病种清单,预习正库卡片
- 轮转中:遇到典型病例 → 回卡片勾「轮转中见过」打卡
- 出科前:补全该科未见的病种,记录遗漏与收获
