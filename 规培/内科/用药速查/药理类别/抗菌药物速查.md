# 抗菌药物速查(β内酰胺/喹诺酮/大环内酯)｜规培背诵版

> 类别:各抗菌药大类代表药+特点速查。定位:药理类别速查,跨科室通用。

## 一、β-内酰胺类

| 亚类 | 代表药 | 特点 |
|---|---|---|
| **青霉素** | 青霉素 G、阿莫西林 | 窄谱;G+球菌;过敏率高(用前皮试) |
| **头孢一/二代** | 头孢唑林、头孢呋辛 | G+为主,皮肤软组织/围手术期预防 |
| **头孢三代** | 头孢曲松、头孢噻肟 | G- 为主,肺炎/胆道/尿路;可过血脑屏障 |
| **头孢四代** | 头孢吡肟 | G+与 G- 兼顾,铜绿部分覆盖 |
| **碳青霉烯** | 美罗培南、亚胺培南 | **最广谱**(含 ESBL、铜绿);重症/耐药菌;特殊使用级 |
| **β内酰胺+酶抑制剂** | 哌拉西林他唑巴坦、头孢哌酮舒巴坦 | 覆盖产酶菌,腹腔/院内感染 |

## 二、喹诺酮类(详见左氧卡)

- 左氧(呼吸+泌尿)、莫西(呼吸+厌氧)、环丙(泌尿+铜绿);**18 岁以下禁、肌腱/QT/光敏**

## 三、大环内酯类

- 阿奇霉素、克拉霉素、红霉素
- 覆盖非典型病原体(支原体/衣原体/军团菌)→ **CAP 联合/首选之一**
- 注意:QT 延长、胃肠道反应;与克拉霉素的药物相互作用(CYP3A4)

## 四、其他大类速记

| 类 | 代表药 | 特点 |
|---|---|---|
| 氨基糖苷 | 阿米卡星、庆大霉素 | G- 需氧菌;**肾毒性+耳毒性**,联合用 |
| 糖肽类 | **万古霉素** | MRSA/G+耐药菌;特殊使用级;监测血药浓度、肾毒性 |
| 噁唑烷酮 | **利奈唑胺** | 抗 G+ 耐药菌;骨髓抑制 |
| 硝基咪唑 | **甲硝唑** | **厌氧菌**(腹腔/胆道/牙周) |
| 四环素 | 多西环素 | 非典型病原体;8 岁以下儿童/孕妇慎 |

## 一句话速记

**β内酰胺看代数,碳青霉烯最广谱;喹诺酮 18 禁,大环内酯管非典型;万古打 MRSA,甲硝唑治厌氧。**
