# 抗菌药物速查｜按病原与部位思考

> 规培学习卡。选药前先核感染诊断、严重度、部位、过敏史、肾肝功能、本院药敏与处方权限；具体处方由带教医师和本院规范决定。

## 常见类别

| 类别 | 代表药 | 要核查的边界 |
|---|---|---|
| 青霉素类 | 青霉素 G、阿莫西林 | 覆盖范围因药而异；询问过敏史，皮试按具体制剂与本院制度 |
| 头孢菌素 | 头孢唑林、头孢呋辛、头孢曲松、头孢吡肟 | “第几代”不能代替药敏；中枢感染、围术期预防须核具体药与场景 |
| 碳青霉烯 | 美罗培南、亚胺培南西司他丁、厄他培南 | 可用于某些严重耐药菌感染；厄他培南不覆盖铜绿假单胞菌；并非所有重症的默认起点 |
| β-内酰胺/酶抑制剂 | 哌拉西林他唑巴坦等 | 不能仅凭“有酶抑制剂”推断覆盖 ESBL；结合部位、药敏与严重度 |
| 大环内酯 | 阿奇霉素、克拉霉素 | 非典型病原体；核 QT、相互作用及当地耐药 |
| 氟喹诺酮 | 左氧氟沙星、莫西沙星、环丙沙星 | 适应证、药敏和风险因药而异；部分常见感染有更合适替代时应避免滥用 |
| 糖肽/噁唑烷酮 | 万古霉素、利奈唑胺 | 考虑耐药革兰阳性菌时再评估；万古霉素按本院 AUC/TDM 流程监测 |
| 硝基咪唑 | 甲硝唑 | 针对特定厌氧菌；腹腔或胆道感染仍须评估需氧菌覆盖与源控制 |

## 选药与复评

1. 明确是感染还是定植/非感染；记录部位、重症程度、过敏史、既往耐药菌和近期抗菌药。
2. 不延误危重患者救治的前提下，先留取有价值的培养标本；按本院经验方案起始，随后结合培养与药敏缩窄或调整。
3. 每日复评感染证据、源控制、剂量和肾功能、口服转换及疗程；疗程依具体感染综合征，不套统一天数。

**记忆句：先定病原概率和部位，再核药敏、宿主风险与本院权限。**
