# 心衰五联药(HFrEF)｜规培背诵版

> 慢性射血分数降低心衰(HFrEF)标准用药:**新四联(指南基石)+ 利尿剂(症状控制)**。
> 原则:**尽早启用、低剂量联合优于单药加量**;监测血压/心率/血钾/肌酐。

## 一、新四联(改善预后,必考)

| 联 | 药物 | 关键点 |
|---|---|---|
| **① ARNI/ACEI/ARB** | **沙库巴曲缬沙坦**(首选 ARNI)起始 50mg bid → 靶剂量 200mg bid;或 ACEI/ARB | **ARNI 与 ACEI 不联用,换药需洗脱 36h** |
| **② β 受体阻滞剂** | 美托洛尔缓释/比索洛尔/卡维地洛 | 小剂量起始,每 2~4 周倍增至靶剂量或最大耐受 |
| **③ MRA(醛固酮拮抗剂)** | **螺内酯 20mg qd** | **警惕高钾血症、肾功能恶化**;肌酐明显升高/高钾慎用 |
| **④ SGLT2i** | **达格列净/恩格列净 10mg qd** | **无论有无糖尿病**均获益 |

## 二、第五类:利尿剂(症状控制,不改善预后)

- **袢利尿剂为主**:呋塞米/托拉塞米(口服或静脉)
- 用于**缓解淤血**(水肿、肺水肿、呼吸困难);剂量按体重/尿量调整
- 注意:低钾、低钠、低血压、肾前性氮质血症;与 MRA 联用监测血钾

## 三、启动与滴定(考点)

- 顺序:血流动力学稳定后**尽早启动四联**,低剂量联合、逐步滴定
- **ARNI 禁忌/不耐受 → ACEI 或 ARB**;四联均不耐受个体化
- 监测:每次调量前后查**血压、心率、血钾、肌酐**;症状控制后利尿剂可减量

## 一句话速记

**心衰四联:沙库巴曲+β阻+螺内酯+达格列净;五联加呋塞米控症状;ARNI 与 ACEI 不碰头,螺内酯怕高钾。**
