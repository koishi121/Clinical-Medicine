# 奥曲肽（生长抑素类似物）｜带教核对卡

> 学习用途：先辨认**短效注射液**与**长效肌注制剂**，再核对适应证、院内制剂浓度和处方权限；本页不能直接作为医嘱。

## 适用场景与边界

| 场景 | 要点 |
|---|---|
| 疑似急性食管静脉曲张出血 | 属于早期血管活性药物选择之一；同时完成复苏、抗菌药预防与紧急内镜止血评估。药物不能代替内镜或其他确定性治疗。胃静脉曲张出血的内镜策略可能不同。 |
| 肢端肥大症 | 用于手术、放疗等效果不充分或不适合的患者；根据 GH、IGF-1 和症状评估。 |
| 转移性类癌综合征、VIP 瘤 | 针对潮红或分泌性腹泻等症状；并非所有神经内分泌肿瘤的通用抗肿瘤药。 |
| 急性胰腺炎、胰瘘 | **不列为常规一线治疗或可照抄的医嘱**。若专科讨论个别病例，核对病因、证据、院内方案与监测。 |

## 成人方案示例：仅限所列场景

- **疑似急性静脉曲张出血**：AASLD 指南表列奥曲肽短效制剂静脉起始 **50 μg**，随后 **50 μg/h** 连续输注，疗程 **2–5 天**；ESGE 指南支持在疑似出血时及早给予血管活性药并维持至多 **5 天**。这是特定出血场景的指南示例，实际注射液浓度、稀释、泵速及调整须由本院流程和带教核对。**不可把它套用于胰腺炎、类癌或长效制剂。**
- **肢端肥大症**：美国短效注射液说明书的初始示例为 **50 μg 皮下注射、每日 3 次**，后续按生化反应和耐受性调整。国内制剂及适应证需核对本院药品说明书；长效肌注制剂不能与短效注射液按毫克数互换。

## 首次核对与监测

- 出血患者：持续看生命体征、出血表现、血红蛋白趋势及内镜后再出血；不得因用药而延迟内镜。
- 用药期间：关注血糖升降、心动过缓或传导异常；长期用药关注胆囊结石/胆泥、甲状腺功能及脂肪吸收问题。
- 糖尿病、心脏传导疾病、肾/肝功能受损、妊娠或儿童患者须个体化，不能照搬成人示例。
