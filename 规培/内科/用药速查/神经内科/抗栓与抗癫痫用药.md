# 神经内科：抗栓与抗癫痫用药｜带教核对卡

> **先排除脑出血、识别卒中病因或发作类型，再开药。** 抗栓与抗癫痫各有急诊和长期路径，不能按病名直接套用一个方案。

## 卒中/TIA 的抗栓分流

1. 急性局灶神经症状先走卒中绿色通道：明确起病时间，做必要的脑影像以排除出血，评估再灌注治疗资格。**不要在未排除出血前自行给抗血小板或抗凝药。**
2. 缺血性卒中/TIA 二级预防：非心源性病例常使用抗血小板；房颤等心源性栓塞通常考虑抗凝。选择前核对颅内出血/转化风险、梗死范围、肾功能、机械瓣/瓣膜病、并用药及患者可及性。
3. **双联抗血小板只适合特定的轻型非心源性卒中或高危 TIA，通常限时使用**；不是所有卒中永久双联，也不应把抗血小板加抗凝作为常规二级预防。房颤的单用阿司匹林不能替代合适的抗凝。
4. 出血性卒中、接受溶栓/取栓的患者及近期大面积梗死者有不同的抗栓时机和逆转路径，应由卒中团队按现行指南处理。本卡不提供可复制的药物起始时间或剂量。

## 癫痫用药：先确定发作类型

| 情况 | 药物学习重点 | 复核点 |
|---|---|---|
| 首次疑似发作 | 先排查低血糖、脑血管病、感染、中毒/戒断等诱因，转专科评估复发风险 | 不能仅凭一次抽搐直接长期用药 |
| 局灶性发作 | 拉莫三嗪、左乙拉西坦等可作为首选单药候选 | 根据年龄、肾功能、药物相互作用、精神行为症状等选药；拉莫三嗪需警惕皮疹 |
| 全身强直阵挛发作 | 药物选择与局灶性发作不完全相同 | 丙戊酸的生殖风险、肝病和其他禁忌必须单独核对；不能自动作为所有患者首选 |
| 癫痫持续状态或反复成簇发作 | 按本院急救路径和既有个体化计划处置，保障气道并纠正诱因 | 不能仅增加日常口服维持药等待；抗癫痫药突然停用也可能诱发发作 |

妊娠或备孕、儿童、肾肝功能受损患者应由相关专科讨论具体制剂和监测。NICE 药物排序反映英国适用范围；中国可及性、说明书及处方权限需另核。
