# 内分泌科常用药(降糖/甲状腺)｜规培背诵版

> 类别:口服降糖药 + 胰岛素;抗甲状腺药 + 左甲状腺素。
> 定位:内分泌轮转开药速查;与正库糖尿病/甲亢/甲减卡「治疗」联动。

## 一、降糖药

| 类别 | 代表药 | 考点 |
|---|---|---|
| **二甲双胍** | 二甲双胍 | **2 型糖尿病一线首选**;注意胃肠反应、**肾功能不全(eGFR<30 停)**、碘造影剂前后暂停 |
| 磺脲类 | 格列美脲、格列齐特 | 促胰岛素分泌;**低血糖**、体重增加 |
| DPP-4i | 西格列汀、利格列汀 | 低血糖少;利格列汀肾功不全无需调量 |
| SGLT2i | 达格列净、恩格列净 | 心肾获益;**泌尿生殖道感染**、酮症(正常血糖性) |
| GLP-1RA | 利拉鲁肽、司美格鲁肽 | 减重+心肾获益;胃肠道反应 |
| **胰岛素** | 门冬(速效)/甘精、德谷(长效) | **1 型必需**;2 型口服失效/急性并发症/围手术期;注意低血糖 |

**要点**:二甲双胍一线、个体化 HbA1c 目标;**低血糖识别与处理**(意识清楚口服糖,昏迷静推葡萄糖)。

## 二、甲状腺用药

| 场景 | 药物 | 考点 |
|---|---|---|
| **甲亢** | **甲巯咪唑(MMI)首选**;丙硫氧嘧啶(PTU) | **MMI:粒细胞缺乏**(发热咽痛即查血常规)、肝损;**PTU:妊娠早期(孕 1~3 月)首选**;β阻滞剂控制症状 |
| **甲减** | **左甲状腺素(L-T4)** | **空腹晨服**、起始小剂量(老年/冠心病更慢);按 TSH 调量;替代过量 → 房颤、骨质疏松 |

## 一句话速记

**二甲双胍一线守肾功;甲巯咪唑防粒缺,怀孕早期换 PTU;甲减晨起空腹补左甲状腺素。**

- [ ] 会识别低血糖并处理;会开 MMI/PTU 与 L-T4
