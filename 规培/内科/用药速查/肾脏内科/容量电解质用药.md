# 肾脏内科：容量与电解质用药｜带教核对卡

> 先辨认**容量不足、容量过多、急性肾损伤、慢性肾病以及电解质紊乱的紧急程度**。同一种化验异常可能需要完全不同的处置；本卡不提供可直接复制的高钾或补液医嘱。

## 首诊核对

- 看血压、呼吸、末梢灌注、体重变化、出入量和尿量；复核肌酐/eGFR、钠钾、碳酸氢根和既往基线。
- 查近期利尿剂、ACEI/ARB、盐皮质激素受体拮抗剂、NSAID、造影剂、补钾剂以及可能造成腹泻或脱水的药物。
- **高钾伴心电图异常、严重肺水肿、症状性严重低钠或明显酸中毒**需立即按本院急救与肾脏替代治疗路径处理，不等待常规门诊用药讨论。

## 轮转常见决策

| 场景 | 药物/措施的作用 | 容易误用之处 |
|---|---|---|
| 容量过多、肺/外周水肿 | 袢利尿剂可用于相应容量负荷；观察体重、尿量、血压、肌酐和钠钾 | 不能把利尿剂当作“治疗急性肾损伤本身”的药；低血容量时可能加重灌注不足 |
| 容量不足 | 按病因、循环状态和合并心衰选择液体；边补边看反应 | 不能按肌酐升高机械大量补液；警惕肺水肿 |
| 高钾 | 先确认是否溶血假性升高，做心电图并评估紧急性；钙剂、促钾转移治疗、排钾手段和透析各有不同目的 | **静脉钙仅稳定心肌，不清除体内钾**；不同钙盐和浓度不可互换；胰岛素方案有低血糖风险，须按院内急救流程 |
| 慢性肾病伴反复高钾 | 排查药物、代谢性酸中毒和饮食中的高生物利用度钾；在可行情况下保留有预后获益的药物 | 不应看到一次高钾就永久停用所有 RAAS 抑制剂；复查和个体化调整 |
| 低钠 | 判断低钠真假、血浆渗透压、容量状态、起病急慢及神经症状 | 不可不分病因套用“补盐”或自由水限制；过快纠正有神经系统风险 |

## 特殊人群与监测

老年、心衰、妊娠、透析患者以及尿量显著下降者需格外谨慎。所有静脉液体、利尿、降钾和纠钠计划都要有**复查时间、停药/升级条件和带教复核**。
