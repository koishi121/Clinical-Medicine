# 血液内科：贫血治疗用药｜带教核对卡

> **先辨贫血类型与病因，再决定补铁、补维生素、促红细胞生成或输血。** 只有血红蛋白低，不能直接开“补血药”。

## 首诊分流

- 核对血常规、网织红细胞、外周血涂片、铁蛋白/转铁蛋白饱和度、维生素 B12/叶酸；结合炎症、肾功能、溶血指标及月经/消化道失血史。
- 出血不止、胸痛、晕厥、呼吸循环不稳或疑似急性溶血者先按急症处理。慢性稳定贫血的药物计划不能取代抢救和病因评估。

## 常见治疗路径

| 病因或场景 | 可考虑的治疗 | 必须复核 |
|---|---|---|
| 缺铁性贫血 | 找失血或吸收障碍病因，同时口服铁盐；不耐受、吸收不良或持续失血可讨论静脉铁 | 先确认真性缺铁；口服剂型所含元素铁量不同，不能把“几片”跨产品复制；静脉铁按具体产品计算并监测输注反应 |
| 维生素 B12 缺乏 | 根据病因和神经症状选择口服或肌注补充 | 有神经症状时不等化验全部完成才开始处理；避免只补叶酸而漏诊 B12 缺乏 |
| 叶酸缺乏 | 明确病因后补叶酸 | 同时评估 B12 状态，避免掩盖神经损伤风险 |
| 慢性肾病相关贫血 | 先评估铁状态，按肾内科方案讨论铁治疗、促红细胞生成药物 | ESA 不是所有贫血通用药；监测血压、血红蛋白变化和血栓风险 |
| 输注红细胞 | 依据症状、出血速度、合并心血管病及输血规范决定 | 不可把单一 Hb 阈值用于所有患者；输后临床及 Hb 复评，后续仍需病因治疗 |

**口服铁的英国指南学习示例**：确诊成人缺铁性贫血时，可从一种常用口服亚铁盐**每日一片**开始；胃肠道不耐受时讨论**隔日一片**或其他途径。建议在开始后约 **4 周**复查 Hb 反应，Hb 恢复后继续补充约 **3 个月**以补足铁储备。**这不是中国任何铁剂的统一剂量**，处方必须根据实际制剂元素铁含量和患者情况核对。

## 规培复盘

- [ ] 能解释同样 Hb 下降时，缺铁、B12 缺乏、CKD 和急性出血的用药为何不同。
- [ ] 能找到患者实际铁剂的元素铁含量，并规划复查与病因调查。
