# ADR 0005 — 模拟试卷批量判答回填收官与卡↔题锚点双向互通

## 状态
已采纳（2026-09-06）

## 背景
- ADR 0004 之后，自动化仅能可靠提取约 16% 答案，剩余 **1468 题**留作「人工对照原书绿色答案回填」——
  但逐题翻书全量回填成本极高，且原书答案以绿色印刷、OCR 必然丢色，无法自动直读。
- 12 个单元（3 套 × 4 单元）实际推进中发现：绝大多数题可按医学知识判答（含解析精要提示），
  仅少量是 OCR 分页截断（题干/选项缺页）无法作答。
- 卡内真题反链（ADR 0004 决策 4）是**纯文本索引**（`卷X·U1·#N … · 答案`），不可点击跳回《模拟试卷汇总.md》对应题，
  复习时无法「卡 ↔ 真题」互跳。

## 决策
1. **判答回填管线 `tools/exam_answers.py`（v2，带出现序号）**：
   - `--dump 卷=X 单元=Y` → 导出该单元全部待核题到 `tools\_tbd\卷X·第Y单元.md`，题块标 `T{no}#{occ}`；
     `occ` 为出现序号，用于消歧 **OCR 同题号多块**（不同题干/选项的重复题块）。
   - 判答写入 TSV（6 列：卷 / 单元 / 题号 / occ / 答案 / 备注）；判答**按医学知识，不核对原书绿答**；
     把握不高的注 `(推断)`；OCR 截断题（题干/选项缺失）**不填、留待核**。
   - `--apply <tsv>` → 回填汇总答案行 + `答案核对清单.md`「参考答案」列。
2. **待核对工作单 `tools/export_tbd.py`**：从汇总现扫答案行仍为 ⚠️ 的题，生成
   `资料\模拟试卷\汇总\待核对题清单.md`（104 题，按卷/单元分组，附题干/选项残文与缺失标签），
   作为翻书人工回填的工作单；幂等可重跑，随回填进度自动减少。
3. **卡↔题双向互通 `tools/upgrade_exam_links.py`**：把卡内真题反链升级为**可点击链接**，
   指向《模拟试卷汇总.md》对应题块标题锚点：
   - 锚点采用 **VS Code / GitHub 同款 `githubSlugifier` 规则**——标题小写、剔除 `·`/括号等一切非
     [字母/数字/_/空格/-] 字符、空白转 `-`；同标题重复块按渲染器 builder 规则追加 `-1/-2…`。
   - 相对路径由卡文件目录计算到汇总文件；重复题号块在题干后加 `〔块k/m〕` 提示。
   - **幂等**：每次从汇总全量重算并整体替换卡内真题 blockquote；**内置自检**——
     模拟汇总全部题目标题的 slug 集合，断言每个链接 fragment 命中（663 链接 0 未命中）。
   - 顺带刷新答案状态（判答回填后卡上「待核」→ 真实字母）。
4. **诚实标注不冒充**：所有判答答案均带来源标记（`(教材推断)`/`(推断)` 等），与 ADR 0004 的
   可靠/推导/待核三档同源，保留可核性。

## 权衡
- 用「按知识判答 + 显式标注」换取全卷覆盖率，代价是未与原书逐题核对的题仍可能错——
  应试前建议对 `(推断)` 与剩余 104 待核抽核原书。
- `occ` 出现序号让 apply 能精确回填 OCR 重复题号的多块，代价是 dump/TSV 必须携带该序号。
- 精确锚点跳转依赖查看器 slug 算法一致（VS Code 与 GitHub 同用 githubSlugifier，已按源码对齐并自检）；
  若在其它渲染器（如 Typora/Obsidian）打开，锚点规则可能略有差异，届时按目标渲染器微调 `slugify`。
- 剩余 104 待核为 OCR 截断题（题干/选项缺页），**无法可靠自动作答**，只能对照原书补全题干后回填。

## 影响
- `tools\exam_answers.py` / `tools\export_tbd.py` / `tools\upgrade_exam_links.py` 常驻 tools；
  今后判答或改汇总后重跑对应脚本即可同步（全部幂等）。
- 汇总答案行、核对清单「参考答案」、待核对题清单、卡内真题链接四者由脚本统一维护，
  任何一步改动后建议同批次跑 `format_exam_md.py` + `upgrade_exam_links.py` + `export_tbd.py` 刷新。
