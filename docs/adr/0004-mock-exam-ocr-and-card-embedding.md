# ADR 0004 — 模拟试卷 OCR 解析与真题回链接入正库卡

## 状态
已采纳（2026-09-06）

## 背景
- 取得自购正版《国家临床执业医师资格考试全真模拟试卷及精析》（贺银成 2026，华中科技大学出版社），
  69.8 MB / 364 页 / **全扫描无文字层**，需转成可检索、可嵌入正库的学习资产。
- 结构已知：**3 套卷 × 4 单元 × 150 题 = 1800 题** + 每套「答案及精析」+ 书末「临考抢分考点」速记表。
- 正库卡已固化 272 张；目标是把真题按「题 → 病种卡」双向嵌合，刷题即复习卡。

## 决策
1. **OCR 管线加固**：`tools/pdf_text.py` 增加 `--resume / --from N / --to N`、每 12 页落盘 + `gc.collect()`，
   规避长任务静默中断后必然全量重来；OCR 用 rapidocr-onnxruntime 兜底文字层缺失。
2. **解析器 `tools/gen_exam_summary.py`**：按「套-单元」状态机切分题目区/答案区/抢分考点；
   提取题干、选项(A–E)、解析精要；关联卡经卡名/别名匹配正库。产物：
   - `资料\模拟试卷\汇总\模拟试卷汇总.md`（1746 题，含卷-单元-题号/题干/选项/答案/解析精要/关联卡）
   - `资料\模拟试卷\汇总\答案核对清单.md`（待核题表，供人工回填）
3. **答案三档可信度**：①可靠(解析显式「答案为X/故选X/(X)」) ②推导(排除式「故不答A、B、C、D」) ③⚠️待核对。
   自动化仅能确定约 16%，**剩余 1468 题人工对照原书绿色答案回填**，再经脚本 `--apply-answers` 反填。
4. **真题反链 `tools/inject_exam_links.py`**：把 663 条已关联真题按卡聚合并注入每张卡
   `## 考点提示` 标题下，blockquote `> 📝 **2026模拟卷真题**(…):`；幂等（检测标记块跳过）。
5. **二进制不入库**：`.gitignore` 忽略 `资料\模拟试卷\*.pdf`（同大纲 PDF），仅 OCR 文本(.txt)、汇总、脚本入库。
6. **阅读器同步**：`make_reader.py` 重跑，真题回链进入 `索引.html` 页内直搜。

## 权衡
- 绿印答案是印刷信息，扫描 OCR **必然丢色** → 不接受"假装全自动"；采用显式/推导/待核三档 + 核对清单闭环，
  以诚实标注换回可校验性。
- OCR 断行/重页 → 汇总题数 1746 ≠ 1800，逐单元如实报告偏差，不静默修正。
- 关联卡别名较宽（如「糖尿」命中题干含糖尿病病史的外科题）→ 反链偶有跨科噪音，重跑/改别名即可修正。
