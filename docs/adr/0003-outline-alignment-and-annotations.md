# ADR 0003 — 考纲对齐、等级标注与自包含导航

## 状态
已采纳（2026-09-05）

## 背景
- 取得官方大纲：2024 临床执业医师大纲（71 页扫描 PDF）+ 2026 医学人文修订（15 页文字 PDF），需按大纲把工作区全量对齐，并给正库卡片加「掌握/熟悉」优先度。
- VS Code 内置简易浏览器（webview，`file+vscode-resource` 虚拟协议）**不允许在 HTML 页内跳转其它本地文件**，普通走外部链接的索引在该环境一律 404。

## 决策
1. **大纲数字化管线**：`tools/pdf_text.py`（pypdf 文字层 + rapidocr-onnxruntime OCR 兜底）→ 抽文本进 `资料\执业医师大纲\_txt\*.txt`，作为大纲唯一依据；两 PDF 二进制 gitignore。
2. **单元对齐**（以 OCR 为准）：`00` 记六部分总结构 + 2026 时间线；`02` 医学人文按 2026 修订五块 + 单元→考点对照；`01` 基础医学 8 科按考纲单元；`04` 预防医学六单元；`05` 实践技能对齐第六部分（临床思维/体查六部/操作清单）；`06` 中医学基础精确 3 单元（删超纲辨证/中药/针灸）。
3. **等级标注**：每张卡头部加 `> 大纲要求:`——高频↔🔷掌握、小众↔◽熟悉（OCR 缺「要求」列，此为代理标注，精确细目要求以人卫 2026 大纲原文为准，已在 CONTEXT 登记）。
4. **覆盖度对账**：OCR 13 系统细目 vs 正库卡 → `资料\覆盖度对账.md`，缺卡按 🔴建议补 / 🟡可选补；🔴 12 张已补。
5. **自包含阅读器**：`索引.html` = 单文件内嵌全部 Markdown → 页内直读、零文件跳转（webview 可用），顶部 `📊 大纲要求·掌握优先(按系统)` 分区。
6. **双向导航**：根 `大纲导航.md`（六部分 → 全部 223 卡）+ 每张卡反向注入 `> 大纲导航:`；`tools/outline_md.py` 生成。
7. **生成器即配置**：`make_reader / annotate_cards / outline_md / pdf_text` 全部幂等可重跑，加卡/改标注重跑即同步。

## 权衡
- OCR 无「要求」列 → 以高频/小众作掌握级代理，牺牲逐要点精确度；以人卫原文兜底。
- webview 无法跨文件跳转 → 牺牲「逐文件打开」的朴素性，换来单文件自包含、离线可读、双端（VS Code/浏览器）一致。
- 223 卡片导航靠手写易撕裂 → 一律脚本生成、链接校验（Test-Path）把关。
