# ADR 0007 — 实践技能三站卡体系(评分细则内嵌)

## 状态
已采纳(2026-09-19)

## 背景
- 实践技能考试是执医考两大关卡之一(与综合笔试并列),第二站操作与查体重"过程口述+手法",失分点多在细节。
- `05_实践技能\` 原仅有一张 README 检查表,无操作卡;操作内容依赖正库碎片化参考,不利于按考纲逐项练。
- 用户自备 `资料\实践技能评分标准\`(胸/腹/骨/腰穿评分表 docx + 肺/心/腹部查体评分表 + 001~010 问诊查体打分表),是官方评分口径的一手资料。

## 决策
1. **三站文件夹结构**:`05_实践技能\` 按考试三站建文件夹——第一站_临床思维、第二站_体格检查与基本操作(下分「体格检查」「基本操作」)、第三站_机考;05 README 为三站入口表。
2. **操作卡 10 张**(第二站\基本操作):无菌术、手术基本操作、创伤急救、心肺复苏与简易呼吸器、胸/腹/骨/腰穿(各独立)、导尿+胃管(合一)、吸痰吸氧+动静脉穿刺+穿脱隔离衣(合一)。
3. **评分细则内嵌**:每张卡含「评分标准与细则(考官版)」三块——**操作前准备 / 操作过程 / 医学人文素养**,与考官评分表同构;穿刺四卡直接参考评分标准文件夹对应 docx。
4. **体格检查 1 张卡**(六子标题):一般/头颈/胸/腹/脊柱四肢肛门/神经;肺、心、腹部按查体评分表细化采分点;通用「操作前准备+人文」小节(暖手、隐私屏风、站右侧等)。
5. **第一站病史采集与病例分析卡**:问诊内容框架(25分)+ 问诊技巧(15分)+ 病例分析四段式 + 常考病例 10 个(诊断要点+鉴别诊断),对应 001~010 打分表。
6. **资料目录整体移出 git**:`资料\`(含评分标准/教材/试卷/大纲)加入 .gitignore 并取消跟踪,仅本地保存。

## 权衡
- 操作卡"合一/拆分"粒度按用户使用习惯调整(胸腹穿先合后拆、导尿胃管合一等),无绝对最优;卡内相对路径随层级修正。
- 评分细则分值按评分表(如操作前准备 21 分/过程 71 分/人文 2~3 分)标注,但**不同考区评分表可能有差异**——卡中注明"以当年官方通知为准"。
- 资料移出 git 后评分标准无远程备份,依赖本地文件;若换机需自行复制 `资料\`。

## 影响
- 第二站从"清单"升级为"可练卡":10 张操作卡 + 1 张体格检查卡,每卡可对照评分细则自查。
- 第一站病史采集按 25+15 分框架可逐条自评;常考病例表联动正库 14 系统卡片。
- 第三站联动检验速查(心电图/影像/化验 12 卡)。
- 后续新增操作卡/评分表变更时,沿用「评分细则三块 + 对应评分表参考」模式。
