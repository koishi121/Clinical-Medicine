# ADR 0008 — 递归离线阅读器与本地资料边界

## 状态
已采纳（2026-10-20）

## 背景
- `tools/make_reader.py` 原先只读取考试和规培目录的一层文件，嵌套实践技能、用药速查和内科总览页面无法从 `索引.html` 直接查找。
- 生成器还会读取本地资料目录中的清单或说明，使这些资料的路径和正文元数据进入提交版 HTML。
- 阅读器用于离线复习，也需要支持键盘、屏幕阅读器和窄屏查看宽表格。

## 决策
1. `考试/` 和 `规培/` 下的 Markdown 递归收录，各层 README 只收录一次，并按相对路径形成导航分组。Markdown 相对链接以源文件目录为基准，经规范化后精确解析，不按同名文件猜测目标。
2. 本地资料目录完全不参与 HTML 收集；生成页面保留为单文件、离线可打开的阅读器，不引入外部依赖或网络请求。
3. Markdown 继续作为临床正文唯一来源；阅读器只是生成的展示文件，不回写源内容。
4. 页面使用语义化导航/正文区域、可键盘聚焦的章节链接、活动条目状态和搜索播报；正文链接只切换索引条目，避免劫持外链；复选框提供可访问状态名称；宽表格放入可横向滚动区域；打开时不自动聚焦搜索框。
5. 根目录忽略 `.venv/`，避免将项目环境提交到仓库。
6. 正文或工具源码若提及本地资料路径，只在生成的阅读器中替换为省略提示；原始 Markdown 与脚本保持不变。
7. 每个被索引条目在导航中只出现一次；大纲掌握/熟悉等级在临床系统分组内优先排序，不重复建立第二组链接。

## 权衡
- 单文件 HTML 会随收录内容增加体积，但可在无网络环境和简单浏览器中打开，且避免相对路径失效。
- 只按标题、目录和文件名搜索，不内嵌全文搜索索引，以控制文件体积和保持生成逻辑简单。
- 本地资料不会出现在 HTML 或 Git；换机时需要用户自行迁移本地资料目录。

## 验收
- 运行 `python -m unittest discover -s tests -v`。
- 对照 `考试/`、`规培/` 下 Markdown 清单与生成索引，确认无漏项和重复项。
- 检查生成页面没有本地资料路径或正文，核对分组计数与条目数。
- 在桌面和窄屏浏览器检查搜索、键盘跳转、活动状态以及宽表格滚动。
