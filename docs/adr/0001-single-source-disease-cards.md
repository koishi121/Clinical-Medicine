# ADR 0001 — 病种内容单一正本：正库 + 规培导航链接

## 状态
已采纳（2026-09-04）

## 背景
工作区服务两个场景：执医考备考（按科目/系统刷病种考点）与规培轮转（按科室浏览常见病种）。若两处各自复制病种内容，同一病种会出现双份、后续修订容易撕裂。

## 决策
采用「正库 + 规培导航区」：
- **正库**：执医考导向的疾病卡片唯一正本，按临床系统组织（对应考纲系统分章）。
- **规培区**：按科室首页组织的导航入口，仅列病种清单并链接到正库卡片，不复制病种内容。

## 权衡
- 替代方案 A：考试/规培双区各自复制内容 → 导航最直接，但同一病种双份、修订撕裂。
- 替代方案 B：单库病种中心 + 双索引视图 → 无复制，但强制每卡双语境、索引维护成本高。
- 选择本方案的代价：规培区浏览多一跳（科室首页 → 链接 → 正库卡片）；换来疾病内容单一来源、修订不撕裂。
