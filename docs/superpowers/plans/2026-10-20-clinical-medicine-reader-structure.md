- Disease Markdown remains the only clinical-content source; department pages remain navigation and tracking pages.

- Preserve the existing directory structure and all unrelated user changes.
- Exclude all of `资料/` from generated HTML and Git; add root `.venv/` to `.gitignore`.
- Do not revise clinical conclusions as part of this reader and structure task.
