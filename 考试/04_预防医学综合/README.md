# 04 预防医学综合 — 大纲考点清单

> 本单元**不逐病种建卡**,此清单是备考检查表;内容以教材/题库承载。逐项核对时打勾。

## 流行病学
- [ ] 疾病分布(三间分布、常用指标:发病率/患病率/死亡率)
- [ ] 描述性研究(现况调查、生态学研究)
- [ ] 分析性研究(病例对照、队列研究)与偏倚控制
- [ ] 试验性研究(临床试验、社区试验)
- [ ] 筛检试验评价(灵敏度/特异度/预测值)与诊断试验
- [ ] 疾病监测、传染病与慢性病流行病学

## 卫生统计学
- [ ] 统计描述(集中趋势/离散趋势、正态与偏态)
- [ ] 抽样误差与抽样分布、参数估计(可信区间)
- [ ] 假设检验(t 检验、χ² 检验、方差分析、秩和检验)适用条件
- [ ] 相关与回归
- [ ] 研究设计与样本量

## 环境卫生学
- [ ] 环境与健康的关系、环境污染与健康
- [ ] 饮用水卫生(水污染、水质指标)
- [ ] 大气污染与健康
- [ ] 公共场所与住宅卫生

## 职业卫生与职业病
- [ ] 生产性毒物与职业中毒(铅、汞、苯、CO、矽肺)
- [ ] 生产性粉尘与职业性肺部疾病
- [ ] 物理因素危害(噪声、高温、振动)
- [ ] 职业病诊断原则与劳动卫生防护

## 营养与食品卫生
- [ ] 营养素(蛋白质、脂肪、碳水、维生素、矿物质)
- [ ] 膳食结构与膳食指南
- [ ] 食品污染与食物中毒(细菌性、有毒动植物、化学性)

## 社会医学与健康教育(简要)
- [ ] 健康与疾病社会决定因素、健康教育与健康促进
- [ ] 初级卫生保健与社区卫生
