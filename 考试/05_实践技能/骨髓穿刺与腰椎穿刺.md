## 一、骨髓穿刺术

**穿刺部位**:**髂后上棘**(最常用);髂前上棘、胸骨(成人慎选)。

**操作步骤**:
1. 体位:髂后上棘→俯卧/侧卧;髂前上棘→仰卧;胸骨→仰卧肩下垫枕
2. 消毒 → 戴手套 → 铺洞巾 → 麻醉:**2% 利多卡因自皮肤至骨膜浸润,骨膜处多点麻醉**(回抽无血)
3. 固定器调长度(按麻醉针进针深度估计),左手拇示指固定皮肤
4. 进针:**右手持针垂直骨面刺入**,针尖抵骨质后**围绕针体长轴左右旋转缓缓钻入**,阻力突然消失且针固定于骨内 = 进入骨髓腔
5. 拔出针芯,接**干燥注射器,适当用力抽吸 0.1~0.2ml**(多抽外周血稀释骨髓)
6. **涂片**:骨髓液滴载玻片→推片 30°~45° 角稍用力推开,头、体、尾分明,厚薄适宜;同时**做外周血涂片对照**
7. 回纳针芯,穿刺针连同针芯**旋转拔出**,按压 1~2 分钟 → 消毒 → 无菌敷料

## 二、腰椎穿刺术

**穿刺点**:**腰 3~4 间隙**(两侧髂嵴最高点连线与后正中线交点 = L4 棘突,取其上/下间隙)。

**操作步骤**:
1. 体位:**侧卧屈颈、双手抱膝**,背部与床面垂直、腰椎后凸
2. 定位标记 → 消毒 → 戴手套 → 铺洞巾 → 局麻(逐层浸润)
3. 进针:沿间隙正中**垂直缓慢进针**,经**两次落空感**(棘上/黄韧带→硬脊膜)后达蛛网膜下腔
4. 拔出针芯见脑脊液流出 → **接测压管测脑脊液压力**(侧卧位正常 70~180mmH₂O)
5. 留取标本 3~4 管(常规/生化/细菌);**Queckenstedt 试验**(必要时,疑椎管梗阻)
6. 回纳针芯拔针 → 消毒 → 无菌敷料
7. 术后:**去枕平卧 4~6 小时**,防低颅压头痛

## 三、评分标准与细则(考官版)

**① 操作前准备(约 21 分)**
- 医师:七步洗手、帽子口罩、自我介绍
- 核对:患者信息;骨穿/腰穿核对**凝血象、血常规**;评估适应证禁忌证;麻醉药过敏史;知情同意(口述)
- 物品:骨穿包(骨穿针、固定器、载玻片)/腰穿包(腰穿针、测压管)、碘伏、无菌手套、2% 利多卡因、注射器、试管;**清点器械药品 + 查有效期**

**② 操作过程(约 71 分,违反无菌原则每处扣 2 分)**
- 体位正确(骨穿按部位;腰穿侧卧抱膝背部垂直)
- 麻醉至骨膜多点(骨穿);逐层浸润(腰穿)
- 骨穿:固定器调长度、垂直骨面、旋转钻入、阻力消失判入腔
- 腰穿:垂直缓慢进针、两次落空感、测压
- 骨穿抽液 0.1~0.2ml 勿多;涂片 30°~45°、头体尾分明;外周血涂片对照
- 回纳针芯旋转拔针、按压止血、消毒敷料

**③ 医学人文素养(通用 2~3 分)**
- 操作前后洗手;动作轻柔;保暖遮挡
- 操作中安抚、嘱不适示意;术后告知注意事项(骨穿:穿刺点 24h 保持干燥;腰穿:**去枕平卧 4~6h**)
- 复测生命体征;标本送检;整理用物垃圾分类

## 考点提示(扣分点)

- 骨穿:抽髓过多(>0.2ml 稀释)、不旋转钻入(暴力穿刺)、漏做外周血涂片
- 腰穿:穿刺点过高(损伤脊髓)、体位不正、术后不嘱去枕平卧
- 麻醉不回抽;测压操作错误;标本管数不足
