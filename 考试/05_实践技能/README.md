# 05 实践技能(实践技能考试)

> 实践技能考试与医学综合笔试并列,**两项都通过**才获执业医师资格。本区给三站考纲检查表;技能重在**反复练(操作+口述)**。
> ⚠️ 站次与题型以当年官方通知为准;本表按临床类别通行结构编写。
> 📖 与大纲**第六部分「实践综合」(临床思维、体格检查、基本操作)**对应(见下方三节)。

## 考试结构(临床类别)

- **第一站**:病史采集 + 病例分析(≈大纲「临床思维」)
- **第二站**:体格检查 + 基本操作(≈大纲「体格检查」「基本操作」)
- **第三站**:机考(心肺听诊、影像/心电图判读、医德医风)

## 一、临床思维(第一站:病史采集 + 病例分析)

### 病史采集
- [ ] 一般:主诉、现病史(起病/诱因/部位性质/加重缓解/诊治经过)
- [ ] 既往史、过敏史、用药史、婚育/月经史(女性)
- [ ] 按系统追问 + 鉴别思维(主诉导向)
- 常考主诉:发热、咳嗽咳痰、咯血、呼吸困难、胸痛、腹痛、呕吐腹泻、呕血/黑便、水肿、血尿、尿频尿痛、头痛、意识障碍、关节痛、皮疹等

### 病例分析
- [ ] 诊断与诊断依据;鉴别诊断;**进一步检查**;治疗方案与随访
- 常考病种与**正库 14 系统卡片一一对应** → 复习正库即备技能病例(如慢阻肺、肺炎、高血压、心梗、糖尿病、消化性溃疡、肾综、甲亢…)

## 二、体格检查(第二站·查体,按大纲六大部)

### (一)一般检查
- [ ] 全身状况(生命征、发育体型、营养、意识、面容体位姿态步态)
- [ ] 皮肤、浅表淋巴结
### (二)头颈部
- [ ] 眼(外眼/瞳孔/对光反射)、口(咽/扁桃体)、颈部(甲状腺/气管/血管)
### (三)胸部
- [ ] 肺部视触叩听
- [ ] 心脏视触叩听(瓣膜听诊区)、外周血管检查
- [ ] 乳房检查
### (四)腹部
- [ ] 视触叩听(移动性浊音、Murphy 征、压痛反跳痛)
### (五)脊柱、四肢、肛门
- [ ] 脊柱、四肢关节、直肠指检
### (六)神经系统
- [ ] 神经反射(深/浅反射)、脑膜刺激征(颈强直/Kernig/Brudzinski)、病理反射(Babinski)

> 要点:手法规范 + **边做边口述**(考官重过程)

## 四、第三站 · 辅助检查判读

- [ ] 心电图:窦律、房颤、心梗(见正库心血管卡)、传导阻滞、室速
- [ ] 影像:X 线(肺炎、气胸、骨折、结石)、CT(肺癌、脑出血)、超声(腹水、胆囊、妇产)
- [ ] 化验:血常规、生化、血气、尿常规(与正库各卡「诊断」字段联动)
- 检验速查背诵合集(肝功/肾功/血常规/凝血/血气/心肌酶/尿常规/腹水):[`03_临床医学综合\检验速查\README.md`](../03_临床医学综合/检验速查/README.md)
- 与正库联动:各病种卡的「诊断」章节即判读素材

## 备考节奏建议

- 平时跟随规培科室在床旁/模拟人反复练操作与查体
- 与正库同步:刷系统卡时顺手练该系统的查体与病例分析
- 技能考前 2 个月专门启动,按本检查表逐项对照补漏
