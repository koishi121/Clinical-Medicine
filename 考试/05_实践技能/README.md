# 05 实践技能(实践技能考试)

> 实践技能考试与医学综合笔试并列,**两项都通过**才获执业医师资格。技能重在**反复练(操作+口述)**。
> ⚠️ 站次与题型以当年官方通知为准;本区按临床类别通行结构编写。
> 📖 与大纲**第六部分「实践综合」(临床思维、体格检查、基本操作)**对应。

## 考试结构(临床类别,三站)

| 站次 | 内容 | 入口 |
|---|---|---|
| **第一站** | 临床思维:病史采集 + 病例分析 | [`第一站_临床思维\`](第一站_临床思维/README.md) |
| **第二站** | 体格检查 + 基本操作(10 张操作卡) | [`第二站_体格检查与基本操作\`](第二站_体格检查与基本操作/README.md) |
| **第三站** | 机考:心肺听诊、影像/心电图判读、化验、医德医风 | [`第三站_机考\`](第三站_机考/README.md) |

> 一句话:**第一站"想"(问病史+病例分析)、第二站"做"(查体+操作)、第三站"看"(听诊+影像+心电图)**。

## 备考节奏建议

- 平时跟随规培科室在床旁/模拟人反复练操作与查体
- 与正库同步:刷系统卡时顺手练该系统的查体与病例分析
- 第三站判读素材 = 检验速查(`03_临床医学综合\检验速查\`)12 张卡
- 技能考前 2 个月专门启动,按三站检查表逐项对照补漏
