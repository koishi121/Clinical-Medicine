## 一、静脉穿刺(采血/置管)

1. 核对、解释;**扎止血带**(穿刺点上方 6cm)、嘱握拳
2. 选择静脉(肘正中/贵要/头静脉);消毒 → 戴手套
3. 绷紧皮肤,**针头斜面向上,与皮肤呈 15°~30°** 刺入,见回血 → 采血/置管
4. 松止血带、嘱松拳;拔针**按压穿刺点**(勿屈肘),止血后贴敷料

## 二、动脉穿刺(血气分析)

1. 部位:**桡动脉最常用**(股动脉、肱动脉)
2. **Allen 试验**:同时压迫桡/尺动脉→握拳发白→松开尺动脉,**10 秒内转红 = 阳性(尺动脉代偿良好)**方可桡动脉穿刺
3. 消毒;**45° 进针(或垂直)**,见鲜红血液自动涌入针筒(动脉压)
4. 采血后**立即排尽气泡、隔绝空气**,**按压 5~10 分钟**(防血肿)
5. 标本 30 分钟内送检(冰浴);**注明吸氧浓度(FiO₂)**

## 三、穿脱隔离衣

**穿**:
1. 摘手表、挽袖过肘;手持衣领取隔离衣(清洁面向自己)
2. 一手伸袖,另一手**提衣领向上拉**,换手穿另一袖
3. 系领扣 → 系袖口 → **背后对齐衣边,向一侧折叠,系腰带**
4. 戴手套(手套口包住袖口)

**脱**:
1. 解腰带 → 解袖口;**塞好衣袖**(袖管塞入工作服袖内)
2. 七步洗手(清洁手)或消毒
3. **脱手套 → 解领扣 → 一手伸入另一袖内拉下衣袖**(勿碰清洁面)→ 换手同法拉下
4. 双手退出,**隔离衣清洁面向外挂衣架(清洁区)**,污染面向外(污染区)
5. 洗手

⚠️ 穿脱全程:**隔离衣清洁面/内面不触碰污染面**;领口为清洁区(脱时最后解、手不触衣外)。

## 四、评分标准与细则(考官版)

**① 操作前准备(约 5 分)**
- 仪表:工作服、帽子口罩、洗手(穿隔离衣前挽袖摘表)
- 核对患者、解释;物品口述(采血针/注射器/止血带/碘伏棉签;隔离衣/手套)

**② 操作过程(主体分)**
- 静脉:扎止血带部位、15°~30° 进针、松带顺序、按压
- 动脉:**Allen 试验**、45° 进针、排气泡隔绝空气、**按压 5~10 分钟**、注明 FiO₂
- 隔离衣:穿——提领穿衣、系带顺序;脱——洗手、脱手套、解领、卷袖退出、挂衣(清洁面外)
- 无菌原则贯穿

**③ 医学人文素养(通用 2~3 分)**
- 操作前后洗手;动作轻柔
- 穿刺前解释、穿刺后嘱按压;注意保暖遮挡
- 整理用物、垃圾分类(污染废物入黄色袋)

## 考点提示(扣分点)

- 动脉穿刺不做 Allen 试验;采血气不排气泡/不隔绝空气;按压不足致血肿
- 静脉采血止血带过久、拔针后屈肘(致皮下淤血)
- 隔离衣穿脱顺序错(先解领扣)、手触污染面、挂衣方向错
