## 一、吸痰术

1. 核对患者、解释;评估痰液情况(听诊痰鸣音);吸氧者提高氧浓度 1~2 分钟
2. 连接吸痰器/中心负压,**调节负压(成人 40~53.3kPa / 300~400mmHg)**
3. 戴手套、连接吸痰管,**试吸生理盐水检查通畅**
4. 插入:**关闭负压(折管/不按侧孔)状态下,沿口/鼻腔/气管切开处插入**(10~15cm)
5. 吸痰:**开启负压,边旋转边缓慢退出**,每次**<15 秒**
6. 间隔 1~3 分钟(吸氧恢复)再吸;**一次连续吸痰 ≤3 次**
7. 观察痰液性状/量、患者面色呼吸血氧;冲洗管道;整理

⚠️ 吸痰前**充分给氧**;严格无菌(气管内吸痰用无菌管);动作轻柔防黏膜损伤。

## 二、吸氧术(鼻导管/面罩)

1. 核对患者、解释;**检查鼻导管通畅**;湿化瓶装水
2. 清洁鼻腔;连接氧源 → **调流量**(鼻导管 **2~4L/min**;面罩 5~8L/min)再与患者连接
3. 固定;观察缺氧改善(面色/呼吸/血氧)
4. 停止吸氧:先撤导管,再关流量表

⚠️ **COPD 患者:低流量 1~2L/min 控制性氧疗**(防 CO₂ 潴留抑制呼吸)。

## 三、动/静脉穿刺

**静脉穿刺**:
1. 扎止血带(穿刺点上方 6cm)、嘱握拳;选择静脉(肘正中/贵要/头静脉)
2. 消毒 → 戴手套;绷紧皮肤,**针头斜面向上,与皮肤呈 15°~30°** 刺入,见回血 → 采血/置管
3. 松止血带、嘱松拳;拔针**按压穿刺点**(勿屈肘),止血后贴敷料

**动脉穿刺(血气分析)**:
1. 部位:**桡动脉最常用**(股动脉、肱动脉)
2. **Allen 试验**:同时压迫桡/尺动脉→握拳发白→松开尺动脉,**10 秒内转红 = 阳性(尺动脉代偿良好)**方可桡动脉穿刺
3. 消毒;**45° 进针(或垂直)**,见鲜红血液自动涌入针筒(动脉压)
4. 采血后**立即排尽气泡、隔绝空气**,**按压 5~10 分钟**(防血肿)
5. 标本 30 分钟内送检(冰浴);**注明吸氧浓度(FiO₂)**

## 四、穿脱隔离衣

**穿**:摘手表挽袖 → 手持衣领取隔离衣(清洁面向自己)→ 伸袖(另手提衣领上拉)→ 系领扣 → 系袖口 → 背后对齐衣边向一侧折叠系腰带 → 戴手套(手套口包袖口)

**脱**:解腰带 → 解袖口塞衣袖 → 洗手 → 脱手套 → 解领扣 → 一手伸入另一袖内拉下衣袖(勿碰清洁面)→ 换手同法拉下 → 双手退出,**清洁面向外挂衣架(清洁区)/污染面向外(污染区)** → 洗手

⚠️ 穿脱全程:**领口为清洁区**(脱时最后解、手不触衣外);清洁面/内面不触碰污染面。

## 五、评分标准与细则(考官版)

**① 操作前准备(约 5 分)**
- 仪表:工作服、帽子口罩、洗手(隔离衣穿前挽袖摘表)
- 核对患者、解释;物品口述(吸痰管/负压装置/无菌手套/生理盐水;氧源/湿化瓶/鼻导管;采血针/注射器/止血带/碘伏;隔离衣/手套)

**② 操作过程(主体分)**
- 吸痰:调负压、**插管关负压退出开负压**、<15 秒/次、连续 ≤3 次、观察血氧
- 吸氧:**先调流量再连接**、固定、观察;COPD 低流量;停氧先撤导管后关流量
- 静脉:止血带部位、15°~30° 进针、松带顺序、按压
- 动脉:**Allen 试验**、45° 进针、排气泡隔绝空气、**按压 5~10 分钟**、注明 FiO₂
- 隔离衣:穿——提领穿衣系带顺序;脱——洗手、脱手套、解领、卷袖退出、挂衣方向

**③ 医学人文素养(通用 2~3 分)**
- 操作前后洗手;动作轻柔防损伤
- 操作前解释、操作中安抚;注意保暖遮挡
- 整理用物、垃圾分类(污染废物入黄色袋)

## 考点提示(扣分点)

- 吸痰:插入时开负压(损伤黏膜);时间过长(缺氧);不预氧
- 吸氧:先接患者再调流量;COPD 高流量;停氧顺序反
- 动脉穿刺:不做 Allen 试验;不排气泡;按压不足致血肿;静脉采血拔针后屈肘
- 隔离衣:穿脱顺序错(先解领扣)、手触污染面、挂衣方向错
