## 一、体格检查(按大纲六大部)

- [ ] (一)一般检查:全身状况、皮肤、浅表淋巴结
- [ ] (二)头颈部:眼(瞳孔/对光反射)、口咽、颈部(甲状腺/气管/血管)
- [ ] (三)胸部:肺视触叩听、心脏视触叩听、乳房
- [ ] (四)腹部:视触叩听(移动性浊音、Murphy 征、压痛反跳痛)
- [ ] (五)脊柱四肢肛门:脊柱、四肢关节、直肠指检
- [ ] (六)神经系统:神经反射、脑膜刺激征、病理反射(Babinski)
