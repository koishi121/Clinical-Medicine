## 定义
慢性非特异性肠道炎症性疾病,包括**溃疡性结肠炎(UC)** 与**克罗恩病(CD)**;病因与免疫/遗传/环境相关。

## 临床表现
- **UC**:腹泻黏液脓血便、里急后重,病变局限于结直肠(自直肠向近端连续);可有肠外表现(结节性红斑、虹膜炎、关节痛)
- **CD**:慢性腹痛(右下腹常见)、腹泻(非脓血为主)、体重下降、瘘管/肛周病变;病变**节段性、全层、可累及全消化道**
- 并发症:UC 中毒性巨结肠、癌变(病程长);CD 瘘管、狭窄、穿孔

## 诊断
- 内镜 + 病理:UC=结肠镜连续充血糜烂/假息肉、隐窝脓肿;CD=节段性铺路石样、非干酪样肉芽肿(深溃疡)
- 钡剂/CTE 小肠段查 CD;粪便钙卫蛋白辅助
- 需除外感染性肠炎、结核、淋巴瘤

## 溃疡性结肠炎分期与分度(必考)

### 1. 临床类型(病程分期)

| 类型 | 特点 |
|---|---|
| **初发型** | 首次发作,无既往病史 |
| **慢性复发型**(最常见) | 缓解期与发作期交替 |
| **慢性持续型** | 症状持续 >6 个月,间有加重 |
| **急性暴发型** | 起病急、病情重,可伴中毒性巨结肠 |

### 2. 病变范围(蒙特利尔分型)

- **E1 直肠型**:局限于直肠
- **E2 左半结肠型**:脾曲以远(直肠+乙状结肠+降结肠)
- **E3 广泛结肠型**:脾曲以近,乃至全结肠

### 3. 活动度与严重程度(改良 Truelove-Witts 分度)★

| 指标 | 轻度 | 重度 |
|---|---|---|
| **血便次数(次/日)** | <4 | **≥6** |
| **脉搏(次/分)** | 正常 | >90 |
| **体温(℃)** | 正常 | >37.8 |
| **血红蛋白** | 正常 | <75% 正常值 |
| **ESR(mm/h)** | <20 | >30 |

- **中度**:介于轻度与重度之间(4~6 次日便血)
- **重度** = 6 指标中 ≥某一临床重型标准(通行:≥6 次血便 + 至少 1 项全身中毒指标);**重症/暴发型需住院、静脉激素,警惕中毒性巨结肠**

### 4. 内镜分级(Mayo 内镜评分)

| 分级 | 表现 |
|---|---|
| 0 | 正常或缓解期 |
| 1 | 轻度:红斑、血管纹理减少、轻度易脆 |
| 2 | 中度:明显红斑、血管纹理消失、易脆、糜烂 |
| 3 | 重度:**自发性出血、溃疡**

> 进阶:**Mayo 评分(0~12 分)**= 排便次数+便血+内镜+医师评价,用于临床试验疗效判定。

### 5. 缓解期判定

- 临床缓解:无症状或血便消失;**内镜缓解**:Mayo 内镜 0~1 分(黏膜愈合 = 治疗目标)

## 治疗
- 氨基水杨酸(美沙拉嗪):UC 轻中度一线;远端可灌肠
- 激素:中重度诱导缓解(不作维持)
- 免疫抑制剂(硫唑嘌呤)、生物制剂(抗 TNF:英夫利昔单抗;维得利珠单抗等)用于激素依赖/难治
- CD:营养支持 + 瘘管处理;狭窄/梗阻、穿孔、大出血→手术
- 监测:癌变风险(UC 病程长)→结肠镜随访

- 结肠镜+病理确诊;肉芽肿指 CD
- 中毒性巨结肠:突发腹胀+肠鸣消失+全身毒血→急症外科
- 激素只诱导不维持原则常考
