# 腹穿四管判读｜背诵版

> 腹腔穿刺抽液四管:常规、生化、细胞学、细菌学(培养+药敏);用于腹水性质鉴别。

## 四管送检
1. **常规管**:外观、颜色、比重、细胞计数与分类
2. **生化管**:总蛋白、白蛋白、LDH、葡萄糖、淀粉酶
3. **细胞学管**:脱落细胞(肿瘤细胞)
4. **细菌学管**:细菌培养 + 药敏(无菌操作,先送)

## 渗出液 vs 漏出液(核心考点)

| 指标 | 漏出液(非炎性) | 渗出液(炎性/肿瘤) |
|---|---|---|
| 外观 | 清亮、淡黄 | 混浊、可血性/脓性 |
| 比重 | <1.018 | >1.018 |
| 总蛋白 | <25g/L | >30g/L |
| 细胞数 | <100×10⁶/L | >500×10⁶/L |
| 常见病因 | 肝硬化、心衰、肾病综合征、低蛋白 | 感染(结核/细菌)、肿瘤、胰腺炎 |

**Light 标准(胸水/腹水)**:胸水蛋白/血清蛋白>0.5 或 LDH>200U/L 或胸水LDH/血清LDH>0.6 → 渗出液

## 特殊腹水
- **血性腹水**:肿瘤、结核、外伤
- **乳糜性腹水**:淋巴管阻塞(肿瘤/丝虫)
- **SAAG(血清-腹水白蛋白梯度)**:≥11g/L → 门脉高压性(肝硬化);<11g/L → 非门脉高压性(肿瘤/结核/胰腺)
- **ADA(腺苷脱氨酶)**:腹水 ADA>45U/L → 高度提示**结核性腹膜炎**(与渗出液+淋巴细胞为主结合判断)

## 一句话速记
**漏出清亮蛋白低(肝硬化心衰),渗出混浊蛋白高(感染肿瘤);SAAG≥11 想门脉高压,血性想肿瘤结核。**
