# ALT/AST(肝细胞损伤酶)vs ALP/γ-GT(胆汁淤积酶)对比

> 肝功两大酶系对比背诵;关联:[γ-GT 与 ALP(胆汁淤积酶)](γ-GT与ALP胆汁淤积酶.md)。

## 对比表

| 维度 | ALT/AST(肝细胞损伤酶) | ALP/γ-GT(胆汁淤积酶) |
|---|---|---|
| **反映** | 肝细胞损伤/坏死 | 胆道/胆管损伤、胆汁淤积 |
| **来源** | 肝细胞(ALT 胞浆、AST 胞浆+线粒体) | ALP:肝胆+骨骼;γ-GT:肝胆为主(几乎不在骨骼) |
| **升高场景** | 病毒性肝炎、药物性肝损伤、脂肪肝、缺血 | 胆道梗阻、PBC/PSC、胆汁淤积性肝炎;γ-GT 还见于酒精/药物/脂肪肝 |
| **关键比值** | **AST/ALT>2 → 酒精性肝病**;ALT>AST 常见于病毒性肝炎 | ALP↑+γ-GT↑ → 肝胆源性;ALP↑、γ-GT 正常 → 骨来源 |
| **骨骼干扰** | 无 | ALP 受骨骼影响(青少年/妊娠/骨病),γ-GT 不受 → 用 γ-GT 鉴别 |

## 一句话速记
**ALT/AST 看肝细胞伤,AST/ALT>2 想酒精;ALP/γGT 看胆汁淤,ALP 单高多是骨,γGT 升高警惕酒。**
