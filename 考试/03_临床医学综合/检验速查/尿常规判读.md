# 尿常规判读｜背诵版

> 尿常规十项速查:比重/酸碱/蛋白/糖/酮体/潜血/白细胞/亚硝酸盐/胆红素/尿胆原。

## 关键项目判读

| 项目 | 异常意义 |
|---|---|
| **蛋白尿** | 肾病综合征(大量蛋白尿>3.5g/d)、肾炎、糖尿病肾病;微量白蛋白尿=早期肾损害 |
| **血尿(潜血+)** | 肾小球源性(变形红细胞+红细胞管型→肾炎)、非肾小球(结石/肿瘤/感染) |
| **白细胞+亚硝酸盐+** | **尿路感染**(亚硝酸盐阳性提示肠杆菌科) |
| **酮体+** | DKA、饥饿、长期禁食 |
| **葡萄糖+** | 糖尿病、肾性糖尿 |
| **胆红素+** | 梗阻性黄疸(直接胆红素↑) |
| **尿胆原↑** | 溶血性黄疸、肝细胞性黄疸 |
| **比重** | 固定低比重(1.010)→ 肾浓缩功能差(尿崩/肾小管) |

## 管型速记
- **红细胞管型**:肾小球肾炎(肾小球源性血尿标志)
- **白细胞管型**:肾盂肾炎/间质性肾炎
- **颗粒/蜡样管型**:慢性肾病
- **脂肪管型**:肾病综合征

## 一句话速记
**蛋白尿想肾病,血尿分肾小球(管型)与非肾小球(结石);白细胞+亚硝酸盐=感染;酮体想DKA。**
