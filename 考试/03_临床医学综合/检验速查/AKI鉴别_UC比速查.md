# AKI 鉴别速查(UC比)｜背诵版

> 急性肾损伤(AKI)肾前性 vs 肾性(ATN)鉴别;注意**两个 UC 比**(考试经常混)。

## ⚠️ 两个 UC 比(先分清!)

1. **血 BUN/Scr(血尿素/血肌酐,很多教材叫 UC 比)**——血液标本,最常考
2. **尿肌酐/血肌酐 UCr/PCr(尿/血肌酐比值,也叫 UC 比)**——尿液+血同时采样

## 一、血 BUN/Scr(最常考,血液标本)

单位:**mg/dL**(老教材;SI 单位 mmol/L 不能直接套 20,考试默认 mg/dL)

- **肾前性 AKI**:**BUN/Cr >20:1**
  机制:肾小管功能完好,尿素重吸收↑;肌酐几乎不重吸收 → 尿素升高更明显
- **肾性(ATN)**:**BUN/Cr <10~15:1**
  机制:肾小管坏死,尿素不能被重吸收,尿素、肌酐同步升高
- **肾后性**:早期类似肾前(>20);梗阻久了肾小管受损,比值下降,偏向肾性

⚠️ **考点坑**:消化道出血、高蛋白饮食、激素、分解代谢高 → BUN 单独升高,比值也 >20,**不是肾前性**!

## 二、尿肌酐/血肌酐 UCr/PCr(尿/血肌酐)

- **肾前性**:**UCr/PCr >40**——肾小管浓缩、保肌酐能力完好
- **肾性 ATN**:**UCr/PCr <20**——肾小管上皮坏了,重吸收受损,尿肌酐低
- **20~40 之间 = 灰区**,不能确诊

## 三、配套联合指标(简答必写,单独 UC 比不能确诊!)

| 指标 | 肾前性 | ATN(肾性) |
|---|---|---|
| **UCr/PCr** | >40 | <20 |
| **尿钠 UNa** | <20 mmol/L | >40 mmol/L |
| **FENa 钠排泄分数** | <1% | >2% |
| **尿比重** | >1.018 | <1.012 |
| **尿渗透压** | >500 | <250 |
| **尿沉渣** | 透明管型 | 棕色颗粒管型 |

**FENa 公式**(考题常一起出):
$$FE_{Na}(\%)=\frac{尿钠}{血钠}\div\frac{尿肌酐}{血肌酐}\times100$$

## 四、肾后性怎么看?

- 肾后**不能靠 UC 比单独区分**:
  - 梗阻早期:肾小管功能还在 → 类似肾前(BUN/Cr>20、UCr/PCr 高)
  - 梗阻持续很久,肾小管坏死 → 指标和 ATN 一模一样
- 👉 **肾后首选泌尿系 B 超看双肾积水**,尿液指标只做辅助

## 五、一句话背诵版(答题直接写)

1. **血 BUN/Scr(mg/dL)>20 提示肾前性;<10~15 提示肾性 ATN**
2. **尿肌酐/血肌酐(UCr/PCr)>40 支持肾前,<20 提示肾实质损伤 ATN**
3. 肾后性尿液指标不特异,需 B 超排查梗阻;**不能单凭 UC 比下诊断,结合尿钠、FENa、尿沉渣、临床病史**

## 一页口诀(选择题快速判断)

**BUN/Cr 血里看,>20 肾前 <15 肾性;UCr/PCr 尿血比,>40 肾前 <20 肾性;尿钠低 FENa 低比重高渗透压高 = 肾前;反之为 ATN;肾后 B 超找积水;消化道出血 BUN 假高别上当。**
