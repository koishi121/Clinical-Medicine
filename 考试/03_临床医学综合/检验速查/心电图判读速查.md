# 心电图判读速查｜背诵版

> 技能考第三站·辅助检查判读:心电图速查。重点:窦律、房颤、心梗、传导阻滞、室速。

## 正常心电图
- **P 波**:心房除极;窦性 P 波在 Ⅰ/Ⅱ/avF 直立、avR 倒置
- **PR 间期**:0.12–0.20s(房室传导)
- **QRS**:0.06–0.10s(心室除极)
- **QT 间期**:<0.44s
- **ST 段**:等电位线;T 波与 QRS 主波方向一致

## 高频判读(必考)

| 心电图 | 特征 |
|---|---|
| **窦性心动过速** | 窦性 P 波,心率>100 次/分 |
| **窦性心动过缓** | 窦性 P 波,心率<60 次/分 |
| **房颤(AF)** | **P 波消失,代之以 f 波**,RR 绝对不齐;心室率快时需控制 |
| **房扑** | P 波消失,锯齿样 F 波(Ⅱ/Ⅲ/avF 明显) |
| **室上速(SVT)** | 心率 150–250,节律规整,QRS 窄 |
| **室速(VT)** | **宽 QRS(>0.12s)+ 心率快**,节律可略不齐;血流动力学不稳→电复律 |
| **室颤(VF)** | 无 P-QRS-T,不规则颤动波;立即 CPR+除颤 |
| **Ⅰ°房室阻滞** | PR 间期>0.20s,每个 P 后均有 QRS |
| **Ⅱ°Ⅰ型(文氏)** | PR 逐渐延长,直至 QRS 脱落 |
| **Ⅱ°Ⅱ型** | PR 固定,突然 QRS 脱落 |
| **Ⅲ°房室阻滞** | P 与 QRS 完全无关(房室分离),心室率慢 |

## 心肌梗死定位(核心考点)
- **急性心梗**:ST 段弓背向上抬高 + 病理性 Q 波 + T 波倒置
- **前壁**:V1–V3;**广泛前壁**:V1–V6;**下壁**:Ⅱ、Ⅲ、avF;**侧壁**:Ⅰ、avL、V5–V6
- 对应冠脉:前降支(前壁)、右冠/回旋支(下壁)

## 一句话速记
**房颤 P 消失 f 波 RR 乱;室速宽 QRS 快;室颤立即除颤;心梗 ST 弓背抬+Q 波;下壁看 ⅡⅢavF。**
