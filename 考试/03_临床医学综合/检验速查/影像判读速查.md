# 影像判读速查(X线/CT/超声)｜背诵版

> 技能考第三站·辅助检查判读:影像速查。重点:X 线(肺炎/气胸/骨折/结石)、CT(肺癌/脑出血)、超声(腹水/胆囊/妇产)。

## X 线判读

| 疾病 | X 线特征 |
|---|---|
| **大叶性肺炎** | 肺叶实变,支气管充气征 |
| **支气管肺炎** | 沿支气管分布小片状模糊影(小儿多见) |
| **肺结核** | 上叶尖后段浸润/空洞/钙化;粟粒性=弥漫小结节 |
| **气胸** | 肺压缩线,压缩区无肺纹理,纵隔移位 |
| **胸腔积液** | 肋膈角变钝→液平面(大量) |
| **骨折** | 骨皮质连续性中断;Colles 骨折(桡骨远端) |
| **泌尿系结石** | 肾/输尿管走行区高密度影(阳性结石) |
| **肠梗阻** | 阶梯状液平面,扩张肠袢 |

## CT 判读

| 疾病 | CT 特征 |
|---|---|
| **肺癌** | 肺内结节/肿块,分叶、毛刺、空洞;增强强化 |
| **脑出血** | **脑实质高密度影**(急性期) |
| **脑梗死** | 低密度灶(24h 后显影) |
| **蛛网膜下腔出血** | 脑沟/脑池高密度 |
| **肝脓肿** | 肝内低密度灶+环形强化 |
| **胰腺炎** | 胰腺肿大、胰周渗出/坏死 |

## 超声判读

| 疾病 | 超声特征 |
|---|---|
| **腹水** | 腹腔液性暗区 |
| **胆囊结石** | 胆囊内强回声+后方声影+随体位移动 |
| **急性胆囊炎** | 胆囊壁增厚>3mm、胆囊增大、周围积液 |
| **胆管扩张** | 肝内外胆管扩张(梗阻) |
| **宫外孕** | 附件区包块+盆腔积液(破裂) |
| **肝血管瘤** | 高回声,边界清 |

## 一句话速记
**X 线看气胸肺压缩/骨折断/结石高密;CT 脑出血高密脑梗低密;超声结石强回声伴声影、胆囊壁厚想胆囊炎。**
