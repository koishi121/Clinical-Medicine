# 06 中医学基础 — 大纲考点清单(2024 修订版第五部分)

> 2024 新版临床执业医师大纲**新增「第五部分 中医学基础」**,笔试含中医基础要点(2026 延续)。
> 本单元不逐病种建卡;依据大纲中医学基础部分,以教材/题库承载,逐项核对打勾。

## 中医学基础(大纲要点)
- [ ] 中医学基本特点(整体观念、辨证论治)与阴阳五行学说
- [ ] 藏象学说(五脏六腑、气血津液)
- [ ] 病因病机(六淫、七情、痰饮瘀血;邪正盛衰)
- [ ] 四诊(望闻问切)与辨证(八纲辨证、脏腑辨证)
- [ ] 常见中药性味归经与方剂基础(基本治则治法)
- [ ] 针灸经络基本知识与常用腧穴定位取穴
- [ ] 常见病症(感冒、咳嗽、胃脘痛、眩晕、不寐等)的中医辨证施治要点
- [ ] 中医治未病与养生保健(与「治未病」健康观衔接)

> 备注:占分比例小但为大纲正式部分;建议优先掌握「四诊+八纲辨证+常见病证」。
