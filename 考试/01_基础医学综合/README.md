## 一、解剖学(10 单元)
- [ ] 1. 运动系统(骨学与关节学、肌学)
- [ ] 2. 消化系统(口腔/咽/食管/胃/小肠/大肠/肝/胰)
- [ ] 3. 呼吸系统(鼻/喉/气管支气管/肺/胸膜/纵隔)
- [ ] 4. 泌尿系统(肾/输尿管/膀胱/尿道)
- [ ] 5. 生殖系统(男/女)
- [ ] 6. 腹膜
- [ ] 7. 脉管系统(心/动脉/静脉/淋巴)
- [ ] 8. 感觉器(视器、前庭蜗器)
- [ ] 9. 神经系统(脊髓/脑/脑神经/传导路)
- [ ] 10. 内分泌系统

## 二、生物化学(18 单元)
- [ ] 蛋白质、核酸的结构与功能;酶
- [ ] 糖代谢、脂质代谢、生物氧化
- [ ] 氨基酸代谢、核苷酸代谢
- [ ] 遗传信息:复制/转录、蛋白质生物合成、基因表达调控
- [ ] 信号转导、重组 DNA 技术、癌基因与抑癌基因
- [ ] 血液生化、肝生化、维生素、钙磷代谢

## 三、生理学(11 单元)
- [ ] 绪论、细胞的基本功能(膜转运/生物电/肌收缩)
- [ ] 血液(血细胞、血型、凝血)
- [ ] 血液循环(心动周期/心输出量/血压调节/微循环/冠脉)
- [ ] 呼吸(肺通气/肺换气/气体运输/调节)
- [ ] 消化和吸收、能量代谢与体温
- [ ] 尿的生成与排出
- [ ] 神经系统功能(突触/感觉/运动/自主神经)
- [ ] 内分泌(下丘脑-垂体/甲状腺/肾上腺/胰岛/钙磷)
- [ ] 生殖

## 四、医学微生物学(35 单元→浓缩)
- [ ] 总论:微生物基本结构/形态/生理/遗传、消毒与灭菌、噬菌体
- [ ] 细菌感染与免疫、细菌感染检查
- [ ] 病原性球菌/肠道杆菌/弧菌/厌氧菌/分枝杆菌/螺杆菌/动物源性及其他细菌
- [ ] 支原体、立克次体、衣原体、螺旋体、真菌
- [ ] 病毒学总论(基本性状/遗传变异/感染与免疫)
- [ ] 呼吸道/肠道/急性胃肠炎病毒、肝炎病毒、黄病毒、出血热病毒
- [ ] 疱疹病毒、逆转录病毒(HIV)、其他病毒

## 五、医学免疫学(20 单元)
- [ ] 免疫器官、免疫细胞、免疫分子(免疫球蛋白/补体/细胞因子)
- [ ] 白细胞分化抗原、MHC 与抗原提呈
- [ ] 免疫应答(固有+适应、体液+细胞)、黏膜免疫、免疫耐受
- [ ] 抗感染免疫、超敏反应(Ⅰ~Ⅳ)
- [ ] 自身免疫病、免疫缺陷、肿瘤免疫、移植免疫
- [ ] 免疫学检查与防治

## 六、病理学(13 单元)
- [ ] 细胞适应与损伤、损伤的修复
- [ ] 局部血液循环障碍(充血淤血/血栓/栓塞/梗死)
- [ ] 炎症、肿瘤(生长扩散/分类/癌基因)
- [ ] 心血管/呼吸/消化系统疾病病理
- [ ] 泌尿/内分泌/乳腺及生殖系统疾病病理
- [ ] 常见传染病与寄生虫病病理、艾滋病与性传播

## 七、病理生理学(13 单元)
- [ ] 疾病概论;水、电解质代谢紊乱
- [ ] 酸碱平衡紊乱
- [ ] 缺氧、发热、应激
- [ ] 缺血-再灌注损伤、休克
- [ ] 凝血与抗凝血功能紊乱(DIC)
- [ ] 心/肺/肝/肾功能不全

## 八、药理学(按作用系统→浓缩)
- [ ] 药效学与药动学总论
- [ ] 传出神经系统药;中枢神经系统药(镇静催眠/抗癫痫/抗精神/镇痛/解热镇痛抗炎)
- [ ] 心血管药(抗高血压/抗心律失常/抗心绞痛/调脂);利尿脱水药
- [ ] 血液及造血器官药(抗凝/抗血小板/纤溶/止血/抗贫血)
- [ ] 组胺受体阻断药;呼吸/消化系统药;子宫平滑肌兴奋药;肾上腺皮质激素类
- [ ] 甲状腺激素与抗甲状腺药、降糖药
- [ ] 抗菌药概论与 β-内酰胺、大环内酯、氨基糖苷、喹诺酮、磺胺类
- [ ] 抗结核/抗真菌/抗病毒;抗寄生虫;抗恶性肿瘤与免疫调节药
