# 01 基础医学综合 — 大纲考点清单

> 本单元**不逐病种建卡**,此清单是备考检查表;内容以教材/题库承载。逐项核对时打勾。
> 依据 2024 修订大纲**基础医学综合共 8 科** = 解剖学、生物化学、生理学、医学微生物学、医学免疫学、病理学、病理生理学、药理学(2026 未变)。

## 解剖学
- [ ] 骨学与关节学(全身骨与关节要点)
- [ ] 肌学(头颈躯干四肢主要肌群)
- [ ] 内脏学(消化、呼吸、泌尿、生殖系统大体结构)
- [ ] 心血管系统(心、动脉、静脉、淋巴)
- [ ] 感觉器(视器、前庭蜗器)与神经系统(脊髓、脑、脑神经、传导路)

## 生理学
- [ ] 细胞的基本功能(膜转运、静息/动作电位、兴奋-收缩耦联)
- [ ] 血液(血型、凝血/纤溶、生理性止血)
- [ ] 循环(心动周期、心输出量、血压调节、微循环、冠脉循环)
- [ ] 呼吸(肺通气、肺换气、气体运输、呼吸调节)
- [ ] 消化(胃肠运动与分泌、消化液、吸收)
- [ ] 体温与能量代谢
- [ ] 尿的生成(肾小球滤过、重吸收、尿浓缩稀释)
- [ ] 神经(突触传递、感受器、反射、自主神经)
- [ ] 内分泌(下丘脑-垂体、甲状腺、胰岛素、肾上腺、钙磷代谢)

## 生物化学
- [ ] 糖代谢(糖酵解、三羧酸循环、糖异生、糖原)
- [ ] 脂质代谢(脂肪酸氧化、酮体、胆固醇、脂蛋白)
- [ ] 氨基酸代谢(转氨、尿素循环、一碳单位)
- [ ] 核苷酸代谢(嘌呤/嘧啶合成与分解)
- [ ] 生物氧化与呼吸链
- [ ] 基因表达(复制、转录、翻译、基因调控)
- [ ] 物质代谢联系与调节

## 病理学
- [ ] 细胞与组织损伤(可逆/不可逆损伤、凋亡)
- [ ] 损伤的修复(再生、肉芽组织、瘢痕)
- [ ] 局部血液循环障碍(充血、淤血、血栓、栓塞、梗死)
- [ ] 炎症(基本病变、类型、炎症细胞)
- [ ] 肿瘤(生长与扩散、良恶性鉴别、癌基因/抑癌基因)
- [ ] 各系统常见疾病病理(心血管、呼吸、消化、泌尿、生殖、淋巴造血等)

## 药理学
- [ ] 药效学与药动学基本概念
- [ ] 传出神经系统药(拟/抗胆碱、拟/抗肾上腺素)
- [ ] 中枢神经系统药(镇静催眠、抗癫痫、抗精神、镇痛、解热镇痛抗炎)
- [ ] 心血管药(抗高血压、抗心律失常、抗心绞痛、利尿、调脂)
- [ ] 血液系统药(抗凝、抗血小板、促凝、抗贫血)
- [ ] 内分泌药(胰岛素与口服降糖药、糖皮质激素、甲状腺药)
- [ ] 抗菌药(β-内酰胺、大环内酯、氨基糖苷、喹诺酮、抗结核、抗真菌)
- [ ] 抗肿瘤药与化疗的基本原则

## 医学微生物学
- [ ] 细菌学总论(结构、生长、消毒灭菌、细菌感染与免疫)
- [ ] 常见致病菌(球菌、肠道杆菌、弧菌、厌氧菌、分支杆菌、衣原体支原体等)
- [ ] 病毒学总论(结构、复制、抗病毒免疫)
- [ ] 常见病毒(肝炎病毒、流感、疱疹、HIV 等)
- [ ] 真菌、立克次体、螺旋体的要点

## 医学免疫学
- [ ] 免疫器官与免疫细胞
- [ ] 抗原、抗体、补体
- [ ] MHC 与抗原提呈
- [ ] 体液免疫(抗体产生、B细胞应答)与细胞免疫(T细胞应答)
- [ ] 超敏反应(Ⅰ~Ⅳ 型)
- [ ] 自身免疫病、免疫缺陷、移植免疫、肿瘤免疫

## 病理生理学
- [ ] 疾病概论与基本病理过程(水电解质酸碱平衡紊乱)
- [ ] 缺氧、发热
- [ ] 应激
- [ ] 休克
- [ ] 弥散性血管内凝血(DIC)
- [ ] 缺血再灌注损伤
- [ ] 心功能不全、肺功能不全、肾功能不全、肝功能不全

> 备注:解剖学与病理生理学为 2024 大纲基础医学综合新增并入(2026 延续);其余 6 科见上。
