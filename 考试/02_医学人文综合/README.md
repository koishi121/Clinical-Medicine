# 02 医学人文综合 — 大纲考点清单(按 2026 修订版)

> 依据:国家医考委《医师资格考试大纲(医学综合考试)》医学人文部分 **2026 年修订版**(国卫医考委发〔2026〕1号)。
> 本单元**不逐病种建卡**,此清单为备考检查表;逐项核对打勾。重点:标注「掌握」的核心项。

## 一、医学人文总论(新增)
- [ ] 医学人文概述(概念/历史/内容/意义,了解)
- [ ] 医学人文关怀:**医疗卫生人员人文素养、实践人文关怀(掌握)**、医学人文精神(熟悉)
- [ ] 医学史(现代医学史、中国医学史、疾病史与健康观,了解为主)

## 二、医学心理学
- [ ] 总论:概念与性质、**医学模式转化(掌握)**
- [ ] 心理过程:认识(感知/记忆/思维)、情绪、意志;需要与动机;人格(气质/性格)
- [ ] 心理健康:概念、标准、不同年龄阶段问题
- [ ] 心理应激与应对、心身疾病
- [ ] 心理评估:测验分类、信度效度常模、常用智力/人格测验、临床评定量表
- [ ] 心理治疗与咨询:精神分析/行为/人本/认知四大流派、**危机干预(掌握)**
- [ ] 医患关系与医患沟通(两种形式/两个水平、沟通技术)
- [ ] 患者心理:患者角色转化、一般心理问题、不同年龄/特殊患者(手术、危重,掌握)

## 三、医学伦理学
- [ ] 伦理学与医学伦理学基本理论
- [ ] 医学伦理指导原则(防病治病救死扶伤/社会主义人道主义/为人民身心健康服务)
- [ ] 基本原则:**尊重/不伤害/有利/公正(掌握)**;基本规范
- [ ] 医疗人际关系伦理:医患关系(模式、权利义务、和谐构建)、医务人员之间
- [ ] 临床诊疗伦理:患者至上/最优化/知情同意/保密守信的**四原则**;诊断/治疗/急救伦理
- [ ] 安宁疗护与死亡伦理:安宁疗护、安乐死、脑死亡标准
- [ ] 公共卫生伦理与健康伦理(社会参与/公益/公正/互助/信息公开)
- [ ] 医学伦理素质养成:教育、修养、评价;中国传统医德

## 四、卫生健康相关法律法规(25 部)
### 公共卫生(8)
- [ ] 卫生法基础知识
- [ ] 基本医疗卫生与健康促进法
- [ ] 传染病防治法(**疫情报告制度、甲类防控措施掌握**)
- [ ] 职业病防治法
- [ ] 疫苗管理法
- [ ] 突发公共卫生事件应对法
- [ ] 医疗废物管理条例
- [ ] 艾滋病防治条例

### 医疗(15)
- [ ] 母婴保健法及其实施办法
- [ ] 献血法
- [ ] **医师法(执业规则、考试与注册、权利义务)**
- [ ] 医疗损害责任(民法典,说明义务/隐私泄露掌握)
- [ ] 精神卫生法
- [ ] 医疗机构管理条例及其实施细则
- [ ] 医疗纠纷预防和处理条例
- [ ] 医疗事故处理条例
- [ ] 人体器官捐献和移植条例
- [ ] 放射诊疗管理规定
- [ ] 处方管理办法
- [ ] 抗菌药物临床应用管理办法
- [ ] 医疗机构临床用血管理办法

### 药品(3) + 中医药(1)
- [ ] 药品管理法及其实施条例(假药/劣药掌握)
- [ ] 麻醉药品和精神药品管理条例(二类精神药品印鉴卡)
- [ ] 药品不良反应报告和监测管理办法
- [ ] 中医药法

## 五、医学人文素养(新增,均掌握)
- [ ] 医德医风
- [ ] 沟通能力
- [ ] 人文关怀
