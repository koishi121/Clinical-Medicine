# 错题集模板

> 用法:复制一行填一条错题(或每条建一个文件);考前按系统/错因集中复习。
> 留在本表即可,git 历史会留痕每次修订。

## 记录字段

- 来源:题库名/真题年份/页码
- 所属系统:如 心血管 / 呼吸 / 内分泌…(对应正库)
- 考点:一句话(如「急性心梗溶栓时间窗」)
- 我的答案 / 正确答案
- 解析要点:错在哪、正确逻辑
- 错因分类:① 知识盲区 ② 思路/鉴别遗漏 ③ 粗心/审题 ④ 数值/公式记忆
- 状态:🔴 待复习 → 🟡 已复看 → ✅ 已掌握

## 使用建议

- 每周回看 🔴 项,掌握后改 🟡/✅
- 按「错因」归类做**系统性补盲**:
  - 集中在粗心 → 做题习惯与审题训练
  - 集中在数值/公式 → 考前背一份数值表
  - 集中在知识盲区 → 回到正库对应卡片补读并打“🟡 在学”
- 定期在 `00_大纲与计划` 里做「错题 → 正库卡片」交叉链接增强记忆
