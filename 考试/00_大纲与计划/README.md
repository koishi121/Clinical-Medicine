# 00 大纲与计划

备考的「宪法层」:考纲依据 + 复习节奏。

## 考纲依据

- 执医考(临床类别) = **实践技能考试** + **医学综合笔试**。
- 医学综合笔试分 4 个单元:① 基础医学综合 ② 医学人文综合 ③ 临床医学综合(分数大头) ④ 预防医学综合。
- 大纲权威来源:国家医学考试网(nmec.org.cn)发布,2026 年指导用书已出版(人卫社)。

## 复习节奏(占位,按你的考试时间细化)

| 阶段 | 内容 | 预计 |
|---|---|---|
| 日常积累 | 按现在轮转科室同步刷对应系统的正库卡片 | 全年 |
| 技能考前 | 实践技能专项(病史采集/病例分析/操作) | 考前 2 月 |
| 综合笔试冲刺 | 大纲考点清单核对 + 真题/模拟 | 考前 3 月 |
