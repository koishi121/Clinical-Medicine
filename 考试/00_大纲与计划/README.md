# 00 大纲与计划

备考的「宪法层」:考纲依据 + 复习节奏。

## 考纲依据

- 执医考(临床类别) = **实践技能考试** + **医学综合笔试**。
- 医学综合笔试分 4 个单元:① 基础医学综合 ② 医学人文综合 ③ 临床医学综合(分数大头) ④ 预防医学综合。
- 大纲权威来源:国家医学考试网(nmec.org.cn);2026 年临床/口腔/公卫等类别**医学人文部分启用 2026 年修订版大纲**(国卫医考委发〔2026〕1号,2026-01-23),临床医学综合仍为 **13 个系统、与 2025 无变动**。
- 大纲文件已下载存:`资料\执业医师大纲\`(`2024年修订临床执业医师大纲.pdf` 总纲 + `2026年修订人文大纲.pdf` 最新修订),抽文本见同目录 `_txt\`。

### 2026 考试时间线(官方公告 2026 年第 1 号)

| 事项 | 时间 |
|---|---|
| 网上报名 | 01-29 ~ 02-11(次年按公告) |
| 现场审核 | 02-27 ~ 03-12 |
| 实践技能考试 | 全国统一时间;**合格线 60 分**(国家基地成绩两年有效) |
| 医学综合第一试 | 计算机化;**执业医师合格线 360 分**(助理 180) |
| 二试(临床/中医) | 09-20 ~ 09-26 报名;成绩查询 第一试 09-19、第二试 11-27 |

## 复习节奏(占位,按你的考试时间细化)

| 阶段 | 内容 | 预计 |
|---|---|---|
| 日常积累 | 按现在轮转科室同步刷对应系统的正库卡片 | 全年 |
| 技能考前 | 实践技能专项(病史采集/病例分析/操作) | 考前 2 月 |
| 综合笔试冲刺 | 大纲考点清单核对 + 真题/模拟 | 考前 3 月 |
